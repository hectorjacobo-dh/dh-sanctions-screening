# Superseded — not part of the product

This directory holds a React/Vite scaffold from the first days of the project.
It was replaced by a single server-rendered page, `backend/app/static/index.html`,
which the API serves directly at `/`. There is no build step and no Node
dependency anywhere in the running system.

Nothing here is used, built or deployed. It is kept only so the early history is
not lost; delete it once you are satisfied nothing references it.
